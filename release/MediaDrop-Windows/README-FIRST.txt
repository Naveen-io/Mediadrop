========================================================================
                       MEDIADROP FOR WINDOWS
========================================================================

Thank you for downloading MediaDrop!
MediaDrop is a high-speed, ad-free social media media-processing web app.

QUICK START (3 EASY STEPS):
------------------------------------------------------------------------
1. PREREQUISITE:
   Ensure you have Python 3.10+ installed on your computer.
   Download Python: https://www.python.org/downloads/
   *IMPORTANT*: During Python installation, check the box:
   "Add Python to PATH"

2. FIRST TIME SETUP:
   Double-click "Setup MediaDrop.bat"
   This will automatically configure a lightweight local Python virtual
   environment and install the necessary dependencies.
   (Note: If you already run "Start MediaDrop.bat", it will run setup
   automatically for you!)

3. LAUNCH:
   Double-click "Start MediaDrop.bat"
   - MediaDrop will start the backend engine and web interface.
   - It will automatically open your default browser at http://localhost:3000
   
TO STOP MEDIADROP:
------------------------------------------------------------------------
- Press any key or close the "MediaDrop Launcher" terminal window, OR
- Double-click "Stop MediaDrop.bat" to shut down all processes immediately.

OPTIONAL - FFMPEG FOR HIGH BITRATE AUDIO & CONVERSION:
------------------------------------------------------------------------
MediaDrop can download standard media streams immediately.
For full MP3/WAV extraction and precision video trimming:
- Install FFmpeg via PowerShell:
    winget install Gyan.FFmpeg.Essentials
- OR download FFmpeg from https://gyan.dev/ffmpeg/builds/ and drop
  ffmpeg.exe and ffprobe.exe into a "bin" folder in this directory.
